# FoodExpress - Project Overview

## 🎯 Project Description
A full-stack food delivery application inspired by Swiggy, built with modern web technologies.

## 🚀 Live Demo
- **Frontend:** https://foodexpress-online.netlify.app
- **Backend API:** https://foodexpress-backend-bleh.onrender.com

## 🛠️ Tech Stack
- **Frontend:** React, Redux, Tailwind CSS, Parcel
- **Backend:** Node.js, Express, CORS, Axios
- **Deployment:** Netlify, Render

## 📱 Features
- Restaurant listings with search
- Shopping cart functionality  
- Responsive design
- User authentication UI
- Real-time price calculation
